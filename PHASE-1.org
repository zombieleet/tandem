Phase 1 goal: you can use claude-pair every day on a real repository.
Linux first; macOS needs a tester.

How testing works on every item:

- *Auto*: tests Claude writes and runs (=make check=). An item is not
  done until they pass.
- *Visual*: what you check by hand in your own Emacs. Tick the box
  when it looks and feels right, or note what's wrong under it.
- Each milestone ends at a visual gate. The next milestone starts
  after you sign off on the gate.
- Tests never call the real model unless they are marked *live*. Live
  checks use your Claude Code login, so they only run with your OK.

* Decisions
- 19 Nov 2026 :: The daemon is written in Go. It drives your installed
  =claude= in headless stream-json mode instead of using the TypeScript
  Agent SDK. The first TypeScript version of M1 was replaced; the
  protocol and the Emacs side did not change.
- 19 Nov 2026 :: Reviews and permission questions go through
  =--permission-prompt-tool=, served by a stdio MCP helper
  (=claude-paird mcp=) that relays to the daemon's private socket.
- 19 Nov 2026 :: Cancel sends SIGINT to =claude=; the next prompt
  resumes the session with =--resume=.
