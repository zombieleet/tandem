#+title: claude-pair · Phase 2 · Review
#+startup: overview

Phase 2 meets the two requirements phase 1 left open: approve, reject or
ask Claude about each block of changes from a small popup next to it, and
Claude's lines keep a colour until someone other than Claude edits them.
Same rules as phase 1: every change gets automatic tests, live checks
cost money only when you say so, each milestone ends with your visual
check, and a milestone is committed before the next one starts.

* Decisions
- 20 Nov 2026 :: Hunks are computed in Emacs (a line diff, Myers'
  algorithm, in Elisp), because only Emacs has the buffer's live text,
  unsaved changes included. The daemon only words the result for Claude.
- 20 Nov 2026 :: Approving a hunk applies it at once, as its own undo
  step, and saves the buffer if it had no unsaved changes of yours. Claude
  hears the outcome when the last hunk of an edit is decided.
- 20 Nov 2026 :: Reopening earlier chats stays in phase 3, as the plan
  has it (the resume picker).
