#+TITLE: tandem · Phase 5 · Release
#+STARTUP: overview

Phase 5 makes tandem ready for other people. Each milestone has
automatic checks, a check by you, and its own branch; a commit follows
your "Mx passed". Anything that leaves this machine (a GitHub repository,
a push, a MELPA request) waits for your explicit go-ahead.

Order: what can be done here first (security, name, manual, actions on
code, suggestions, protocol, packaging), then what needs a GitHub repository (CI on macOS and
Windows, the first public release).
