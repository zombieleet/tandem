#+title: claude-pair · Phase 3 · Context
#+startup: overview

Phase 3 gives Claude more of what you see and know in Emacs, and you more
control over where it starts and how far back you can go. Done when: it
works on Linux, macOS and Windows. Same rules as before: automatic tests
for every change, live checks only when needed, your visual check at the
end of each milestone, and a milestone is committed before the next one
starts.

* Decisions
- 21 Nov 2026 :: The git root stays the default project root. Without
  git, the nearest folder with a project marker is the root, never your
  home folder or =/= unless you confirm.
- 21 Nov 2026 :: Slash commands and rewind start with a spike against the
  real =claude= in headless mode, since what it supports there decides the
  design.
